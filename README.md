# پلاک‌یاب ایران

یک PWA شخصی برای خواندن پلاک استاندارد خودروهای سواری ایران و نمایش شهر و استان محل صدور آن.

## وضعیت

این پروژه در حال ساخت است. پردازش تصویر و OCR در مرورگر انجام می‌شود و تصویر یا شماره پلاک به سرور ارسال نمی‌شود.

داده‌ی شهر و استان از جدول‌های عمومی پلاک خودرو گردآوری شده است. نسخه‌ی اول شامل شناسه‌های بررسی‌شده‌ی متداول است؛ برای هر شناسه‌ی موجود، نتیجه منطقه‌ی صدور یا شماره‌گذاری پلاک را نشان می‌دهد، نه مالکیت خودرو یا محل فعلی آن. شناسه‌های ناموجود نتیجه نمی‌دهند و برنامه هرگز حدس نمی‌زند. کدها ممکن است با تخصیص‌های جدید تغییر کنند و داده‌ی پروژه باید با منابع فهرست‌شده در کد به‌روزرسانی شود.

## توسعه

```bash
npm install
npm run dev -- --host 0.0.0.0
```

دسترسی دوربین در محیط production به HTTPS نیاز دارد؛ `localhost` برای توسعه مجاز است. برای آزمایش با تلفن، از آدرس HTTPS گیت‌هاب پیجز پروژه استفاده کنید، نه یک IP محلی HTTP.

## حریم خصوصی

- فریم دوربین فقط در حافظه‌ی گوشی برای اسکن فعلی پردازش می‌شود.
- تصویر، ویدئو، متن OCR و تاریخچه‌ی اسکن ذخیره، ارسال یا رهگیری نمی‌شود.
- برنامه فقط پس از انتخاب «شروع اسکن» درخواست دوربین می‌کند.

## محدودیت‌ها

- فقط پلاک سفید استاندارد خودروهای سواری پشتیبانی می‌شود.
- نور کم، زاویه‌ی زیاد، حرکت، پوشیدگی پلاک و کادر خارج از راهنما ممکن است مانع تشخیص شود.
- برنامه برای کد و حرف ناشناخته حدس نمی‌زند و به اسکن ادامه می‌دهد.
- برای افزایش دقت، پلاک را نزدیک، روشن و روبه‌رو داخل کادر نگه دارید.

## به‌روزرسانی داده‌ی مکان

رکوردها در `src/data/iranPrivatePlateLocations.json` هستند. هر تغییر باید با منابع `src/data/locationSources.ts` تطبیق داده شود، تاریخ بازبینی را به‌روز کند، و برای ترکیب‌های مشترک همه‌ی موقعیت‌های تأییدشده را نگه دارد.

## انتشار در GitHub Pages

پس از push به شاخه‌ی `main`، در تنظیمات مخزن به **Settings → Pages** بروید و **GitHub Actions** را به‌عنوان Source انتخاب کنید. workflow انتشار، سایت را می‌سازد و آدرس HTTPS آن را در اجرای Actions نمایش می‌دهد.
